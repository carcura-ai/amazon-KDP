# Punkteschema im Detail

Jede Teilpunktzahl braucht eine Begründung mit Quelle. Ohne Beleg: 0 Punkte.

## Nachfrage — 25 Punkte

| Punkte | Lage |
|---|---|
| 21–25 | Mehrere Autocomplete-Formulierungen, mehrere Titel mit dreistelligen Rezensionszahlen, erkennbar wiederkehrende Saison |
| 16–20 | Autocomplete vorhanden, mindestens zwei etablierte Titel mit gutem Rang |
| 11–15 | Einzelne Signale, Wettbewerb existiert, aber schwach belegt |
| 6–10 | Nur Vermutung aus verwandter Nische |
| 0–5 | Keine belegbare Nachfrage |

Nie aus einem einzelnen Bestseller auf die Nische schließen — Ausreißer sind häufig.

## Konkurrenzstärke — 20 Punkte (schwächere Konkurrenz = mehr Punkte)

| Punkte | Lage |
|---|---|
| 17–20 | Spitzentitel meist < 50 Rezensionen, veraltet, schwache Cover, kein Verlag |
| 12–16 | Gemischt, ein bis zwei starke Titel, Rest angreifbar |
| 7–11 | Mehrere Titel > 300 Rezensionen, gute Cover, aktive Reihen |
| 3–6 | Verlage oder Lizenzmarken dominieren |
| 0–2 | Nische fest in der Hand einer Marke |

## Erkennbare Marktlücke — 20 Punkte

Punkte nur für eine Lücke, die wir **konkret** schließen können.

| Punkte | Lage |
|---|---|
| 17–20 | Mehrfach genannte Kritik plus fehlendes Angebot für klar umrissene Zielgruppe |
| 12–16 | Eine klare Lücke, z. B. keine Reihe, keine passende Altersstufe |
| 7–11 | Verbesserung möglich, aber austauschbar |
| 3–6 | Nur „schöner machen" |
| 0–2 | Keine Lücke erkennbar |

Beispiele für belegbare Lücken:
- keine eng auf 5–7 Jahre zugeschnittenen Titel, nur 3–8-Sammelangebote
- Kritik „zu wenige Seiten" bei mehreren Spitzentiteln
- kein Titel für die konkrete Nutzungssituation (Auto, Wartezimmer)
- kein Titel mit wiederkehrender Figur
- kein regionaler Bezug trotz Suchnachfrage

## Serienpotenzial — 15 Punkte

| Punkte | Lage |
|---|---|
| 13–15 | Figur und Rahmen tragen ≥ 5 Bände, klare Bandlogik |
| 9–12 | 3 Bände klar planbar |
| 5–8 | Ein Folgeband denkbar |
| 0–4 | Einzeltitel |

## Realistische Marge — 10 Punkte

| Punkte | Deckungsbeitrag je Exemplar |
|---|---|
| 9–10 | ≥ 3,50 EUR bei marktüblichem Preis |
| 6–8 | 2,00–3,49 EUR |
| 3–5 | 1,00–1,99 EUR |
| 0–2 | < 1,00 EUR oder negativ |

Immer mit realistischer Seitenzahl und aktuellem Druckkostensatz rechnen.

## Produktions- und Rechtsrisiko — 10 Punkte (geringes Risiko = mehr Punkte)

Start bei 10, Abzüge:

| Abzug | Grund |
|---|---|
| −4 | Medizinische oder pädagogische Aussagen ohne Fachprüfung möglich |
| −3 | Lizenzfiguren oder Marken prägen die Nische |
| −3 | Reale Personen, Wahrzeichen oder geschützte Motive nötig |
| −2 | Sehr enges Saisonfenster, Vorlauf knapp |
| −2 | Aufwendige Farbillustration bei dünner Marge |
| −2 | Hoher Konsistenzaufwand über viele Figuren |
| −1 | Ausfüllbuch mit erhöhtem Rückläuferrisiko |

Minimum 0.

## Ankerbeispiel

> „Beschäftigungsbuch Autofahrt 5–7 Jahre":
> Nachfrage 19 (Autocomplete belegt, drei Titel > 200 Rezensionen),
> Konkurrenz 14 (gemischt, ein starker Titel),
> Lücke 16 (keine eng auf 5–7 zugeschnittene Reihe),
> Serie 13, Marge 8, Risiko 9 ⇒ **79 = STARTEN**.
> Die Zahlen sind ein Formatbeispiel, kein Marktbefund.
