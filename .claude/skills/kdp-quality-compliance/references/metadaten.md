# Prüfung Metadaten

Metadaten müssen dem tatsächlichen Inhalt entsprechen. Das ist keine Marketingfrage,
sondern eine Regelfrage.

## Titel und Untertitel

- [ ] Titel im Buch, auf dem Cover und in den Metadaten identisch
- [ ] Untertitel beschreibt echten Inhalt
- [ ] Kein Keyword-Stuffing
- [ ] Keine fremden Marken
- [ ] Keine fremden Autorennamen
- [ ] Keine unbelegten Superlative („Nr. 1", „Bestseller", „bestes")
- [ ] Keine Behauptung über Auszeichnungen oder Empfehlungen ohne Beleg
- [ ] Altersangabe stimmt mit dem Inhalt überein

## Beschreibung

- [ ] Jede Aussage trifft auf den Inhalt zu
- [ ] Umfang und Ausstattung korrekt genannt
- [ ] Altersangabe genannt
- [ ] Kein Vergleich mit fremden Marken oder Titeln
- [ ] Keine Versprechen über Lernerfolge („kann danach rechnen")
- [ ] Keine Rezensionszitate ohne Beleg
- [ ] Zulässige Formatierung, sauber geschlossene Tags

## Keywords (7 Felder)

- [ ] Jede Phrase beschreibt das Buch tatsächlich
- [ ] Keine fremden Marken oder Autorennamen
- [ ] Keine Bestseller- oder Rangbehauptungen
- [ ] Keine irrelevanten Begriffe
- [ ] Keine Wiederholung von Wörtern aus Titel/Untertitel ohne Zusatznutzen
- [ ] Keine Begriffe für Inhalte, die das Buch nicht enthält

## Kategorien und Altersangabe

- [ ] Kategorien passen zum Inhalt
- [ ] Keine Kategorie nur wegen schwacher Konkurrenz gewählt
- [ ] Lesealter von–bis konsistent mit Cover, Beschreibung und Inhalt
- [ ] Klassenstufe konsistent

## Autorenname

- [ ] Keine Verwechslungsgefahr mit einem bekannten Autor
- [ ] Bei Pseudonym: über alle Bände konsistent
- [ ] Schreibweise überall identisch

## Reihenangaben

- [ ] Reihenname konsistent über alle Bände
- [ ] Bandnummer korrekt
- [ ] Reihenname im Buch, auf dem Cover und in den Metadaten gleich
