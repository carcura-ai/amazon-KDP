# Prüfung Satz und Druckdatei

> Alle Maßvorgaben vor der Prüfung in den aktuellen KDP-Hilfeseiten und im
> KDP-Vorlagengenerator gegenprüfen und mit Datum notieren. Werte ändern sich.

## Satz und Seiten

- [ ] Keine doppelten Seiten
- [ ] Keine unbeabsichtigt leeren Seiten
- [ ] Kein abgeschnittener Text
- [ ] Seitenreihenfolge korrekt
- [ ] Seitenzahl stimmt mit dem Seitenplan überein
- [ ] Seitenzahl innerhalb der zulässigen Spanne der gewählten Bindung
- [ ] Rechte/linke Seiten korrekt (Kapitelanfänge, Doppelseitenwirkung)
- [ ] Kein Text im Falz einer Doppelseitenillustration

## Druckdatei

| Prüfung | Hinweis |
|---|---|
| Auflösung | ≥ 300 dpi **bei Endgröße**, nicht bei Originalgröße |
| Anschnitt | randabfallende Motive über den Rand hinaus angelegt |
| Sicherheitsabstand | Text und wichtige Bildinhalte weit genug vom Schnitt |
| Innenrand (Gutter) | steigt mit der Seitenzahl — Tabelle prüfen |
| Farbmodus | passend zur gewählten Druckoption |
| Schriften | eingebettet, nicht referenziert |
| Transparenzen | reduziert |
| Dateigröße | innerhalb der KDP-Grenze |
| Seitengröße | einheitlich, exakt die gewählte Trimmgröße |

## Cover

- [ ] Rückenbreite aus der **tatsächlichen** Seitenzahl und dem gewählten Papier berechnet
- [ ] Rückentext nur ab ausreichender Seitenzahl (sonst Versatzrisiko)
- [ ] Kein eigener Barcode und kein Barcode-Platzhalter im dafür vorgesehenen Bereich
- [ ] Titel auf dem Cover identisch mit dem Titel in den Metadaten
- [ ] Altersangabe auf dem Cover sichtbar
- [ ] Reihenkennzeichnung und Bandnummer sichtbar
- [ ] Text im Sicherheitsbereich
- [ ] Cover als ein Dokument über Rück-, Rücken- und Vorderseite

## Lesbarkeit für Kinder

- [ ] Ausreichender Kontrast zwischen Text und Hintergrund
- [ ] Kein Text auf unruhigem Bild
- [ ] Klare Schrift ohne verspielte Ligaturen
- [ ] Ausreichender Zeilenabstand
- [ ] Ausfüllflächen groß genug für Kinderhände
- [ ] Linien zum Schreiben mit passendem Abstand für die Altersstufe

## Druckvorschau

- [ ] KDP-Druckvorschau **vollständig** durchgeblättert, jede Seite
- [ ] Alle Warnungen der Vorschau gelesen und bewertet
- [ ] Screenshot auffälliger Seiten im Compliance-Bericht

## Probeexemplar

Ein physisches Probeexemplar zeigt Dinge, die die Vorschau nicht zeigt:
Papierdurchschlag, tatsächliche Farbwirkung, Bindungsverlust im Falz, Rückenversatz.
