# Bewertungsraster für Chancen

Der Scout liefert **Indikatoren**, keine Punktzahl. Punkte vergibt `kdp-opportunity-validator`.

## Nachfrageindikatoren (je Indikator: Wert + Quelle + Datum)

| Indikator | Deutet auf Nachfrage hin, wenn … | Trügerisch, weil … |
|---|---|---|
| Autocomplete-Vorschlag existiert | Formulierung wird real gesucht | keine Volumenaussage |
| Mehrere Vorschläge um dasselbe Thema | Themencluster vorhanden | Amazon personalisiert teilweise |
| Bestseller in der Nische mit vielen Rezensionen | Markt kauft dort | Rezensionen sind kumuliert über Jahre |
| Mehrere Titel mit starkem BSR | Kategorie bewegt sich | BSR ist Rangwert, keine Stückzahl |
| Google-Trends-Kurve DE steigt saisonal | wiederkehrendes Fenster | relativ, nicht absolut |
| Nachfrage sichtbar, aber Angebot alt/schwach | Lücke | Alter ≠ schlecht |

## Wettbewerbsindikatoren

| Indikator | Bedeutung |
|---|---|
| Anzahl relevanter Titel auf Seite 1 | Grunddruck |
| Wie viele davon aus den letzten 12 Monaten | Dynamik |
| Rezensionsanzahl der Spitzentitel | Einstiegshürde |
| Preisspanne | Preisdruck |
| Covermuster | wie stark visuelle Differenzierung möglich ist |
| Erkennbare Verlage vs. Selfpublisher | Ressourcenvergleich |

## Lückenindikatoren

- wiederkehrende Kritik in Rezensionen (zu wenig Seiten, zu schwer, zu leicht,
  dünnes Papier, Lösungen fehlen, nicht altersgerecht)
- kein Titel für eine **eng definierte** Altersgruppe
- keine echte Reihe, nur Einzeltitel
- kein Titel für die konkrete Nutzungssituation (Auto, Wartezimmer, Restaurant)
- kein Titel mit regionalem Bezug, obwohl Region gesucht wird

## Risikoindikatoren

| Risiko | Prüfen |
|---|---|
| Lizenzfiguren dominieren die Nische | Konkurrenz gegen Marken kaum schlagbar |
| Thema medizinisch/pädagogisch heikel | Fachprüfung durch Menschen nötig |
| Sehr enges Saisonfenster | Vorlauf realistisch? |
| Hohe Seitenzahl / Farbdruck | Druckkosten drücken Marge |
| Aktivitätsbücher zum Ausfüllen | Rückläufer- und Erwartungsrisiko |
| Regionalbezug | kleine Zielgruppe, dafür wenig Wettbewerb |

## Einschätzung am Ende jeder Chance

- **verfolgen** — Nachfrage belegt, Lücke plausibel ⇒ an Validator
- **beobachten** — Signal vorhanden, Beleg zu dünn ⇒ nächster Bericht
- **verwerfen** — keine Nachfrage belegbar oder Risiko zu hoch
