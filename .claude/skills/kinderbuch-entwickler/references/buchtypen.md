# Buchtypen

## Beschäftigungsbuch (Auto, Reise, Restaurant, Regentag, Urlaub)

| Merkmal | Empfehlung |
|---|---|
| Umfang | 60–100 Seiten |
| Farbe | Schwarzweiß-Innenteil (Marge, Kinder malen selbst aus) |
| Aufbau | Blöcke à 4–6 Seiten, Aktivitätstyp wechselt |
| Dauer je Seite | 3–10 min, im Buch angeben |
| Besonderheit | Aufgaben ohne Schere und ohne Kleber, wenn das Buch im Auto genutzt wird |
| Nachspann | Lösungen |

Aktivitätsarten: Suchbild, Labyrinth, Punkte verbinden, Fehlersuche, Zuordnen,
Schattenrätsel, Ausmalen, Zeichnen ergänzen, Wortsuche, Rechenrätsel,
Beobachtungsspiele für unterwegs, Reihenfolge sortieren.

Wichtig für Autofahrten: keine Aufgabe, die Ruhe und exakte Linienführung
gleichzeitig braucht — im fahrenden Auto ist genaues Malen frustrierend.
Große Flächen, klare Linien, Beobachtungsaufgaben nach draußen.

## Vorschul- und Lernbuch

| Merkmal | Empfehlung |
|---|---|
| Umfang | 60–90 Seiten |
| Aufbau | Ein Lernziel je Kapitel, Schwierigkeit steigt sichtbar |
| Wiederholung | Jedes Lernziel mindestens dreimal in Varianten |
| Erfolgserlebnis | Am Kapitelende eine leichtere Seite |
| Erwachsenenseite | Was wird geübt, wie begleiten |

Lernziele nie mit Altersversprechen verknüpfen („kann danach lesen").
Formulierung: „übt", „bereitet vor", „macht vertraut mit".

## Bilderbuchgeschichte (Kindergartenstart, Zahnarzt, Gefühle, Freundschaft)

| Merkmal | Empfehlung |
|---|---|
| Umfang | 24–40 Seiten |
| Farbe | Farbe |
| Aufbau | Ausgangslage → Auslöser → Steigerung → Wendepunkt → Auflösung → Ausklang |
| Text | 40–90 Wörter je Doppelseite |
| Regel | Das Gefühl wird benannt, ernst genommen und aufgelöst |

Bei Zahnarzt, Arzt, Krankheit: Ablauf nur allgemein und beruhigend beschreiben,
keine medizinischen Anweisungen. In die Prüfpflicht-Tabelle eintragen.

## Regionales Kinderabenteuer (Westerwald, Oberbergischer Kreis, Köln)

| Merkmal | Empfehlung |
|---|---|
| Umfang | 32–48 Seiten |
| Orte | Landschaft, Natur, Alltag — allgemein gehalten |
| Vorsicht | Keine geschützten Wahrzeichen-Abbildungen, keine Logos, keine realen Personen, keine realen Firmennamen |
| Chance | Kleine Zielgruppe, wenig Wettbewerb, hohe Identifikation, gute Geschenkeignung |

Reale Ortsnamen dürfen genannt werden. Detailgetreue Abbildungen geschützter
Bauwerke gehen in die Rechteprüfung von `kdp-quality-compliance`.

## Seitenzahl und Bindung

Seitenzahl immer gegen die aktuellen KDP-Vorgaben für die gewählte Bindung prüfen
(Mindest- und Höchstseitenzahl, Innenrand steigt mit der Seitenzahl).
Werte im Seitenplan mit Prüfdatum notieren.
