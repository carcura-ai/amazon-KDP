# Figurenentwicklung

## Charakterbogen

| Feld | Inhalt |
|---|---|
| Name | kurz, deutsch sprechbar, keine Verwechslung mit Markenfiguren |
| Art | z. B. Fuchs |
| Alterseindruck | passend zur Zielgruppe, eher etwas älter als der Leser |
| Grundeigenschaft | eine dominante, in einem Wort |
| Zweite Eigenschaft | ergänzend, erzeugt Reibung |
| Schwäche | macht die Figur nahbar |
| Wunsch | treibt die Handlung |
| Typische Geste | Wiedererkennung im Bild |
| Typischer Satz | Wiedererkennung im Text |
| Zuhause | Ort, der über die Reihe trägt |
| Begleitfigur | Gegenpol |
| Verhältnis zu Erwachsenen | Erwachsene helfen, lösen aber nicht alles |

## Originalitätsprüfung (Pflicht)

Vor der Freigabe schriftlich beantworten:

1. Ähnelt Name oder Klang einer bekannten Buch-, Film- oder Markenfigur?
2. Ähnelt die Silhouette einer geschützten Figur?
3. Ist eine Merkmalskombination (Farbe + Kleidung + Accessoire) charakteristisch
   für eine bestehende Marke?
4. Könnte der Stil als Nachahmung eines benennbaren lebenden Künstlers gelesen werden?
5. Kommen Marken, Logos oder Produktformen im Design vor?

Eine Antwort „ja" oder „unsicher" ⇒ Merkmal ändern, erneut prüfen.
Ergebnis in die Character Bible eintragen.

## Fuchsfigur — Leitplanken für die Marke

Ein Fuchs ist als Tierfigur weit verbreitet. Unterscheidbarkeit entsteht **nicht**
über „ein Fuchs", sondern über eine feste, ungewöhnliche Merkmalskombination:

- eine untypische, aber konsistente Farbabweichung (z. B. eine bestimmte Ohr-
  oder Schwanzspitzenfarbe) mit festem Farbcode
- **ein** unverwechselbares Accessoire, das in jedem Band vorkommt und eine
  Funktion in der Handlung hat
- eine wiederkehrende Geste
- ein wiederkehrender Satz
- ein fester Heimatort mit regionalem Bezug

Nicht verwendbar: Kleidungs- und Farbkombinationen bekannter Fuchsfiguren aus
Film und Verlagsprogrammen; jede Anspielung darauf.

## Nebenfiguren

Zwei bis drei feste Nebenfiguren reichen für eine Reihe. Jede braucht eine eigene
Silhouette und Farbwelt, damit Kinder sie im Bild sofort auseinanderhalten.
Jede Nebenfigur bekommt einen eigenen Character-Bible-Datensatz.
