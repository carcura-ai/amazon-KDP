# Lexware – Leistungen zum Anlegen (Stand 11.11.2026)

Preise = Endpreise laut Website (brutto, inkl. 19 % USt).
In Lexware: **Steuer 19 %**, dann den **Pin auf „VK brutto“ setzen** und den Bruttopreis eintippen –
so bleibt der Endpreis exakt (z. B. 700,00 €) und Lexware rechnet netto selbst aus.
Falls Carcura Kleinunternehmer ist: Steuer 0 %, Preis = brutto.

„ab“-Preise: Basispreis ist hinterlegt, bei Mehraufwand auf der Rechnung anpassen.
